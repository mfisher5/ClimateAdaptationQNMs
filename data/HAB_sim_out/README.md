### HAB simulation output

Output from *QPress* `system.simulate` for HAB perturbations. Each simulation includes 50,000 stable matrices.

Running script 01 in the `scripts` folder should result in the following files in this folder:
- HABhi_x_StatusQuo_AllStrat_50k.rds

Running script 02 in the `scripts` folder should result in the following files in this folder:
- StatusQuo_x_HABhi_50k.rds
- Insurance_x_HABhi_50k.rds
- DisasterRelief1_x_HABhi_50k
- DisasterRelief2_x_HABhi_50k
- ExistingFishDiv1_x_HABhi_50k.rds
- NewFishDiv2_x_HABhi_50k.rds
- SupplementaryDiv_x_HABhi_50k.rds

Running script 03 in the `scripts` folder should result in the following files in this folder:
- Feedback_Infrastructure_x_HABhi_50k.rds

You can also find the exact data files used for publication on Zenodo at: doi.org/10.5281/zenodo.17353735
